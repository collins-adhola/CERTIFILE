# Image Assets

This folder contains all image assets for the CertiFile website.

## Required Images

### Hero Image

- **File:** `hero-image.jpg`
- **Purpose:** Main hero image displayed on the landing page
- **Recommended Size:** 1200x800px or similar 4:3 ratio
- **Usage:** Used in `home.page.html` as the hero section image

### Additional Images

Add any other images for the website here as needed.

## File Naming Convention

- Use lowercase letters
- Use hyphens (-) instead of spaces
- Use descriptive names (e.g., `verification-process.jpg`, `team-photo.jpg`)
